**Verdict:** DISSOLVE

**Summary:** Withdrawability cannot carry "precedes," §11c is the kill-shot the document priced as a footnote, and the shipped conduct gate already substitutes for this island-held pair; the sixth edge is slag as a ring instrument.

**Fatal flaws:**
- **False dilemma, §3a and §11a.** The design spends un-observability because "the alternative is that the ring cannot be gated at all" and because the four-option table has "one member left." Both are false. Strike-context fact 4: the conduct gate covers **100% of the wake path**; ordinary messages never wake; there was no un-gated wake to exempt. The omitted fifth option is the substitute already merged (`b7dafac`). §3a's "proposed anyway" is therefore not a hard remainder. It is a frame that hides SUBSTITUTES.
- **Withdrawability cannot carry precedes (§10 weakness 1, after weakness 3 was struck and weakness 2 was demoted to a scoping note).** §5 gates `POST /v1/dm` create, then claims ring gating "by consequence." A signed withdrawal that **destroys** the channel couples "stop ringing me" to "delete our conversation," so nobody uses it at 3am. A withdrawal that **leaves** the channel does not stop the invite. The unique 3am instrument named in this same document is `#3343` mute (plus the existing send-path block). "I answered them once in 2024" is a mute/block story, not a sixth ADR-0005 edge. Residual set that only unfriend-without-mute serves, at 46 people: near empty. It cannot bear PRECEDES.
- **§5 is a coupling, not a door.** One edge grants DM-create, send, and ring as a single "reach" object, then calls itself low-stakes. Reach is not a rate limit. WhatsApp silences unknown callers without a friend table; Signal's Message Requests are not an identity-graph edge. Gluing those verbs together is how withdrawability becomes theatre.
- **§11c is sound and under-weighed, and the blast radius is larger than §11c wrote.** A signed mutual Principal→Principal table is exactly the 2026-08-25 artifact ("it IS the queryable social graph"). Conduct reads `Message` rows that exist for routing. Equivalent on behavioural inference; strictly worse on the axis of the original objection. **Undercounted:** signed **withdrawal** persists a tombstone graph. At 46 users the sensitive query is not "who talks" (already in DMs) but "who is missing / who withdrew." That table does not exist today. This design mints it.
- **§7 grandfathering collides with §3a and launders a graph out of routing.** The island "cannot mint" a signature. Silent grandfathering therefore either (a) forges island-attested edges, (b) forks the primitive into signed vs derived, or (c) is not grandfathering but a signing campaign that **does** sever anyone who does not sign. Signal grandfathered a **client filter**, not a signed identity edge. The "answers must match §10" line is a rhetorical trap: deriving a **query** from `Message` rows is not the same act as **materialising** `is-friend-of`.
- **§6's recommendation is the spam-frame answer to a consent-frame problem the same document just accepted (§11d / §11e).** Blurred avatars and un-linkified URLs are internet-scale abuse hygiene. At 46 people the value is a **legible** decision. Neutering identity-adjacent signal makes consent worse. MSC2403's reason field reimports the free-text harassment surface the fork claimed to close. And the whole request channel (new endpoint, new limiter, never-wake invariant) exists only if this edge exists as a door.
- **§11a draws the right morning-fact and the wrong arrow of time (Charge E).** RESEARCH.md's headline still names `alert` → NSE → CallKit as the only scale-free escape that fully defeats the structural argument. The same-morning RESOLUTION closed it **for this spike**: `CXError` code 2, missing `com.apple.developer.usernotifications.filtering`, positive control that `didReceive` ran. - **Wrong option-frame against the 2026-08-23 ruling.** That ruling was friends as a **first-class primitive**, not a consent patch bolted to the ring. This document then justifies the primitive **by** the ring, and asks withdrawability to carry PRECEDES so it can be both. If 08-23 still stands, the design that already survived 08-25 (app-local contact list, island builds nothing) is the one. This island table is that design inverted, not amended.
