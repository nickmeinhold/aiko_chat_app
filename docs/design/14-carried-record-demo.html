The trick is that a message, a peer’s judgment, and a moderator’s retraction are the same kind of thing: a signed event on a carried log. So there’s no reputation system to build — only a log to read.

Honest waterline. In Aiko today, messages carry this seal (sign-at-birth shipped). Conduct-judgments don’t yet — the island must sign them first, tracked as issue #2506. This log renders the whole vision so you can see the shape; the amber “judgment” entries are the near future, not today.

A fresh identity carries an empty log — provably thin, and thinness can’t be shed by re-registering. That’s sybil defence without asking anyone to prove they’re a person. Verification here uses only the carried bytes and the signer’s public key: no authority is consulted, none is needed.
