Aiko Chat — Submission Kit

Review information for each App Store version submission. Bundle cc.imagineering.aikoChatApp · App id 6785395468. Aiko Chat is LIVE on the App Store (0.0.1, READY_FOR_SALE) — this kit covers the reviewer-facing details every subsequent version goes back through review with. Auth is passkey-only (social sign-in was removed in PR #69); there is no username/password and no demo account.

⚠️ The one gate before submitting

Verify passkey CREATE works end-to-end on the review build, against chat.imagineering.cc, before hitting Submit — and make sure the App Access note tells the reviewer to tap Create a passkey, not Sign in.

Aiko is passkey-only, so there is no demo account to hand Apple — the reviewer must create their own passkey on the review device. Two things sink this if unchecked, and both bit the Android launch (rejected twice):

  • The reviewer taps "Already have a passkey? Sign in" on a fresh device → no passkey exists yet → dead-end. The in-app nudge (PR #101) now redirects that to "Create a passkey," but the App Access note below must also say it explicitly — reviewers follow the note literally.
  • The review device has no screen lock / biometric enrolled → passkey creation itself can't proceed. The note asks them to enrol one.

Install the review build, tap Create a passkey, authenticate with Face ID / Touch ID, confirm you land in the chat. Only then submit.

Notes for Review (the important one) 
Aiko Chat uses PASSKEYS ONLY — there is no username or password, and no demo
account to provide. Please do NOT tap "Already have a passkey? Sign in": there
is no passkey on a fresh review device yet, so that path will correctly report
"no passkey found."

To sign in:
1. Make sure the review device has a screen lock with Face ID or Touch ID
   enrolled — creating a passkey requires it.
2. On the login screen, tap "Create a passkey" (NOT "Sign in").
3. Authenticate with Face ID / Touch ID. An Aiko account is created
   automatically on your first passkey, and you are taken straight to the chat.

Network: the app connects to https://chat.imagineering.cc — please allow
network access.

UGC compliance: a EULA must be accepted on first launch (zero tolerance for
objectionable content). Users can block other users and report messages from a
long-press menu. Account deletion is available in Settings → Delete Account.

History: how this app reached passkey-only

Aiko originally shipped social sign-in (Sign in with Apple / Google), then a server-side OAuth broker, then pivoted to passkeys as the sole ingress in PR #69 (2026-07-10). The old prod reviewer demo account (task #19) predates all of this and is unusable — passkey-only review needs the reviewer to create their own passkey, per the note above, so no stored credential applies.
